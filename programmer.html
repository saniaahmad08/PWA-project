Overview

Bloom Buddies uses a data.json file to store all flower data. The app reads this file automatically when it loads and builds the menu and content from it. This means you can add, remove, or change flowers simply by editing the JSON file — no changes to the HTML or JavaScript are needed.

JSON File Structure

The data.json file contains one array called flowers. Each flower is an object inside that array with the following fields:

{
    "flowers": [
        {
            "id": 1,
            "title": "Flower Name",
            "text": "A short description of the flower.",
            "image": "assets/images/filename.jpg",
            "audio": "assets/audio/filename.mp3",
            "growing": {
                "sunlight": "How much sun it needs",
                "water": "How often to water it",
                "soil": "What type of soil it needs",
                "season": "Best time to plant it",
                "tip": "A helpful growing tip"
            }
        }
    ]
}

How to Add a New Flower

Step 1 — Add the flower object to data.json

Open data.json and add a comma after the last flower's closing , then paste a new flower object. Example:

{
    "id": 6,
    "title": "Sunflower",
    "text": "Sunflowers are tall, bright yellow flowers that always face the sun.",
    "image": "assets/images/sunflower.jpg",
    "audio": "assets/audio/sunflower.mp3",
    "growing": {
        "sunlight": "Full sun, at least 6-8 hours per day",
        "water": "Water deeply once a week",
        "soil": "Well-drained, slightly acidic soil",
        "season": "Plant seeds in spring after the last frost",
        "tip": "Plant near a fence or wall for wind support!"
    }
}
Step 2 — Add the image file

Save your flower image as a .jpg or .png file and place it in the assets/images/ folder. The filename must match exactly what you wrote in the "image" field in the JSON.

Step 3 — Add the audio file

Save your audio file as a .mp3 and place it in the assets/audio/ folder. The filename must match exactly what you wrote in the "audio" field in the JSON.

Step 4 — Update the service worker

Open service-worker.js and add the new image and audio file paths to the ASSETS_TO_CACHE array so they work offline:

'assets/images/sunflower.jpg',
'assets/audio/sunflower.mp3'

Important Rules

  • Each flower must have a unique id number.
  • File names in the JSON must match the actual file names exactly — including lowercase letters.
  • Always add a comma after the closing of the previous flower before adding a new one.
  • Do not add a comma after the very last flower in the array.
  • All text values must be wrapped in double quotes " ".
  • If your JSON has an error, the menu will not load
Tip: After editing the JSON, open the browser console (right click → Inspect → Console) and reload the page. If there are any errors they will appear in red there.

Changing to a Completely Different Dataset

To change the app to a completely different topic (for example, from flowers to animals), follow these steps:

  1. Replace all the flower objects in data.json with your new topic's objects using the same format.
  2. Replace the image and audio files in the assets/ folders with your new ones.
  3. Update the app name and description in index.html, manifest.json, and style.css.
  4. Update the cache list in service-worker.js to include all new file paths.

No changes to app.js are needed as long as the JSON structure stays the same!
